## Landing video and installation

`nextjs/public/videos/devarena-commercial.mp4` is a 1920 x 1080, six-second motion composite of the original four PNGs. The screen textures stay fixed. Original electronic music and sound effects are synthesized for this asset. The video uses AVC and AAC-LC; all 179 variable-rate video frames decode, with a duration of 6.011 seconds and average 29.777 FPS. It was composed and encoded locally, not generated by an AI video model.

The landing page's `MobileShowcase` section sits between the hero and How it works. It uses a lightweight WebP poster and muted inline looping playback, styled like an animated image without the native player bar. A small accessible pause/play button allows visitors to stop the motion. The final camera return meets the opening macro to avoid an abrupt loop cut. Reduced motion and data-saving preferences disable automatic playback; visitors can still play manually. It pauses when hidden. The movie is not added to the service worker's offline cache.

The existing PWA manifest, icons and service worker are reused. `InstallProvider` shares one deferred browser installation event between the landing button and existing installation banner. iPhone/iPad and Safari visitors receive platform-specific instructions. Dismissing the banner does not disable the landing button. Actual installation completion is driven by the browser's `appinstalled` event or standalone display mode.

To verify installation in CMD, use `npm run build` followed by `npm run start` in `nextjs`, then open `http://localhost:3001`. On a phone, use the deployed HTTPS URL: a plain HTTP LAN IP does not provide the secure context required for PWA installation. In Chrome/Edge use Install DevArena; on iPhone use Safari > Share > Add to Home Screen. Sign-in is still required for protected pages after installation.

The generated video and poster are available at `/videos/devarena-commercial.mp4` and `/videos/devarena-commercial-poster.webp`.
